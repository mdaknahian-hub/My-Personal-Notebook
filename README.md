# দোকান হিসাব — বাকির খাতা ও দোকান ব্যবস্থাপনা 📒

মনোহারী দোকানের মালিকের জন্য বানানো সম্পূর্ণ বাংলা ফুল-স্ট্যাক অ্যাপ। প্রতিটি
কাস্টমারের আলাদা খাতা, বাকি-জমার হিসাব, স্টক, খরচ, সাপ্লায়ার, তাগাদা, রিপোর্ট ও
ব্যক্তিগত নোটবুক — সব একসাথে, মোবাইল-ফার্স্ট ডিজাইনে।

---

## ✨ কী কী আছে

| বিষয় | বিবরণ |
| --- | --- |
| **ড্যাশবোর্ড** | মোট বাকি, আজকের বিক্রি/জমা, মাসিক লাভ, ১৪ দিনের চার্ট, বাকি কত দিনের পুরনো (aging), স্টক সতর্কতা, সেরা কাস্টমার, স্মার্ট পরামর্শ |
| **কাস্টমার খাতা** | প্রতিটি কাস্টমারের আলাদা সূচিপত্র — সার্চ, ট্যাগ, বাকি অনুযায়ী সাজানো, বাকির সীমা, রঙিন অ্যাভাটার |
| **কাস্টমার প্রোফাইল** | চলমান ব্যালেন্সসহ পূর্ণ খতিয়ান, মাসিক সারাংশ, প্রায়ই কেনা পণ্য, তাগাদার ইতিহাস, প্রিন্টযোগ্য হিসাব বিবরণী |
| **লেনদেন** | বাকি / জমা / ছাড় / নগদ বিক্রি — পণ্যের লাইন যোগ করলে স্টক নিজে কমে, তারিখ অনুযায়ী গ্রুপিং, CSV এক্সপোর্ট, সম্পাদনা ও মুছে ফেলা |
| **স্টক** | পণ্যের তালিকা, ক্রয়-বিক্রয় দাম ও লাভের হিসাব, এক ট্যাপে স্টক কমানো-বাড়ানো, "মাল এসেছে" এন্ট্রি, কম স্টক সতর্কতা |
| **খরচ** | দোকান ভাড়া, বিদ্যুৎ, পরিবহন, কুলি, বেতন — খরচের ডোনাট চার্ট ও দিনভিত্তিক তালিকা |
| **সাপ্লায়ার** | কাদের কাছে কত পাওনা, মাল কেনা ও টাকা পরিশোধের হিসাব |
| **রিপোর্ট** | ৩/৬/১২ মাসের বিক্রি-আদায়-খরচ-লাভ, খরচের খাত, সেরা কাস্টমার ও পণ্য, সবচেয়ে ভালো দিন/বার, CSV ও প্রিন্ট |
| **তাগাদা কেন্দ্র** | কত দিন ধরে বাকি — সেই অনুযায়ী তালিকা, এক ট্যাপে হোয়াটসঅ্যাপ/এসএমএস/কল, "কথা দিয়েছেন" নোট, পূর্ণ ইতিহাস |
| **নোটবুক** | রঙিন পিন-করা নোট, ট্যাগ ও সার্চ |
| **সেটিংস** | দোকানের তথ্য, বাকির সীমা, বাংলা/ইংরেজি সংখ্যা, ডার্ক মোড, তাগাদার মেসেজ টেমপ্লেট, পাসওয়ার্ড পরিবর্তন, JSON ব্যাকআপ, ডেমো রিসেট |

## 🔐 ডেমো লগইন

```
মোবাইল নম্বর : 01712345678
পাসওয়ার্ড    : dokan1234
```

প্রথমবার অ্যাপ চালু করলে **স্বয়ংক্রিয়ভাবে ডেমো ডেটা তৈরি হয়** — ১৮ জন কাস্টমার,
৩০০+ লেনদেন, ২৮টি পণ্য, খরচ, সাপ্লায়ার, তাগাদা ও নোট। চাইলে লগইন পেজের
"ডেমো দোকান দেখুন" বাটনে এক ক্লিকেই ঢোকা যায়।

নিজের দোকান খুলতে চাইলে **নতুন দোকান** ট্যাব থেকে রেজিস্টার করুন — নতুন অ্যাকাউন্টে
১২টি স্টার্টার পণ্য দেওয়া হয়।

## 🧱 প্রযুক্তি

- **Next.js 15** (App Router, Server Components) + **React 19**
- **Node-এর বিল্ট-ইন SQLite** (`node:sqlite`) — আলাদা ডেটাবেস সার্ভার বা নেটিভ
  প্যাকেজ লাগে না, সব ডেটা `data/dokan.db` ফাইলে থাকে
- **Tailwind CSS 4** — মোবাইল-ফার্স্ট, ডার্ক মোড সহ কাস্টম ডিজাইন সিস্টেম
- **জেডব্লিউটি সেশন** (`jose`) + **bcrypt** পাসওয়ার্ড হ্যাশ, httpOnly কুকি
- **zod** দিয়ে সব ইনপুট ভ্যালিডেশন
- **Hind Siliguri** ফন্ট (বাংলা টাইপোগ্রাফি)
- બધું JS/TS — কোনো বাহ্যিক সার্ভিস বা ক্লাউড নির্ভরতা নেই

## 🚀 চালু করা

```bash
npm install          # প্যাকেজ ইনস্টল
npm run db:seed      # ডেমো ডেটা তৈরি (ঐচ্ছিক — অ্যাপ নিজেও করে)
npm run dev          # http://localhost:3000
```

প্রোডাকশনের জন্য:

```bash
npm run build
npm start
```

`.env` ফাইলে যা আছে:

```
DATABASE_URL="data/dokan.db"
AUTH_SECRET="যেকোনো-লম্বা-গোপন-স্ট্রিং-দিন"
```

> প্রয়োজনে Node 22.5+ ব্যবহার করুন (`node:sqlite` এর জন্য)।

## 📱 মোবাইলে ব্যবহার

1. মোবাইল ব্রাউজারে অ্যাপটি খুলুন।
2. ব্রাউজার মেনু → **Add to Home Screen** / **Install app**।
3. এরপর অ্যাপের আইকন থেকে খুললে সেটি সাধারণ অ্যাপের মতোই সার্ভিস দেবে
   (standalone, নিজস্ব আইকন, দ্রুত লোড)।

অ্যাপটি মোবাইলের জন্য বিশেষভাবে সাজানো:

- নিচে ৫ ঘর বিশিষ্ট ট্যাব বার, মাঝে বড় **＋** বাটন (দ্রুত বাকি/জমা লেখার জন্য)
- ইনপুট ফিল্ডে ১৬px ফন্ট (মোবাইলে জুম হবে না)
- নিচ থেকে ওঠা শিট-স্টাইল মোডাল, safe-area সাপোর্ট
- নম্বর প্যাড-বান্ধব টাকার ইনপুট (বাংলা অঙ্কে লেখা যায়)

## ⚡ দ্রুত কাজের সুবিধা

- কাস্টমার, পণ্য ও লেনদেন **অপটিমিস্টিক আপডেট** — ট্যাপ করা মাত্র স্ক্রিনে যোগ হয়,
  ব্যাকগ্রাউন্ডে সেভ হয়; ব্যর্থ হলে নিজে থেকে রোলব্যাক + টোস্ট
- লেনদেন লিখতে লেখতেই বাকির হিসাব আপডেট দেখায় ("নতুন বাকি হবে ৳…")
- `Ctrl + K` চাপলে গ্লোবাল সার্চ (কাস্টমার, পণ্য, লেনদেন, নোট)
- `N` চাপলে যেকোনো পেজ থেকেই নতুন লেনদেন
- নেটওয়ার্ক ছাড়া ডেটা ফেচ ব্যর্থ হলে ব্যাখ্যাসহ বাংলা বার্তা + আবার চেষ্টার সুযোগ

## 🗂️ ফোল্ডার কাঠামো

```
src/
├─ app/
│  ├─ (app)/              # লগইনের পরের সব পেজ (ড্যাশবোর্ড, খাতা, স্টক…)
│  ├─ api/                # REST এন্ডপয়েন্ট (auth, customers, transactions…)
│  ├─ login/              # লগইন ও নতুন দোকান
│  ├─ layout.tsx          # থিম, টোস্ট, ফন্ট
│  └─ manifest.ts         # PWA ম্যানিফেস্ট
├─ components/
│  ├─ charts/             # বার, ডোনাট, প্রগ্রেস রিং (SVG)
│  ├─ forms/              # লেনদেন, কাস্টমার, পণ্য, খরচ, সাপ্লায়ার, নোট
│  ├─ layout/             # সাইডবার, মোবাইল নেভ, গ্লোবাল সার্চ, অ্যালার্ট
│  ├─ pages/              # প্রতিটি পেজের ক্লায়েন্ট কম্পোনেন্ট
│  ├─ providers/          # থিম ও অপটিমিস্টিক স্টোর
│  └─ ui/                 # ফিল্ড, মোডাল, টোস্ট, ব্যাজ, স্কেলিটন
├─ lib/
│  ├─ db.ts               # node:sqlite কানেকশন + স্কিমা + হেল্পার
│  ├─ repo.ts             # সব SQL কুয়েরি (ইউজার, কাস্টমার, লেনদেন…)
│  ├─ services.ts         # হিসাব, খতিয়ান, স্টক সমন্বয়, অ্যাক্টিভিটি লগ
│  ├─ queries.ts          # ড্যাশবোর্ড/রিপোর্টের জন্য সমন্বিত কুয়েরি
│  ├─ calc.ts             # বাকি হিসাবের গণিত (pure)
│  ├─ format.ts           # বাংলা সংখ্যা, টাকা, তারিখ, ফোন
│  └─ seed.ts             # বাস্তবসম্মত ডেমো ডেটা
└─ scripts/seed.ts        # npm run db:seed
```

## 🧮 হিসাব কীভাবে হয়

| লেনদেন | বাকিতে প্রভাব |
| --- | --- |
| বাকি (DUE) | বাকি বাড়ে, স্টক কমে |
| জমা (PAYMENT) | বাকি কমে |
| ছাড় (DISCOUNT) | বাকি কমে (মাফ) |
| নগদ বিক্রি (CASH_SALE) | কাস্টমারের খাতায় প্রভাব নেই, দৈনিক আয়ে যোগ হয়, স্টক কমে |

কাস্টমারের বাকি = **আগের বাকি + Σ বাকি − Σ জমা − Σ ছাড়**

প্রতি লেনদেনের পর চলমান ব্যালেন্স খতিয়ানে দেখা যায়, আর কখনো হিসাব গরমিল হবে না।
